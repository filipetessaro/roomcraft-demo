# Roomcraft demo

A packaged Windows build of the Roomcraft demo: unzip and run `RoomcraftDemo.exe`. No engine needed.

Roomcraft is a procedural dungeon and town plugin for Unreal Engine 5.6, 5.7 and 5.8: it builds dungeons and whole towns
from a seed, with your own modular kit, and every house can be walked into, floor by floor. The demo opens in a medieval
town from a random seed; C switches to the dungeon demo.

## Keys

| Key | What it does |
|---|---|
| WASD, mouse, Space | Walk, look, jump |
| F | Fly through walls (Q down, E up), F again to walk |
| R | A new town, or a new dungeon in the dungeon demo |
| C | Switch between the town and the dungeon demo |
| T | Next theme (dungeon demo) |
| G | Grid or rooms joined door to door (dungeon demo) |
| M | Whole map (dungeon demo) |
| H | Hide the keys |
| Esc | Quit |

## What to try

- Walk into any house: the street door opens into furnished rooms, kitchen and workshop by the door, bedrooms upstairs.
- Fly over the town with F: the canal with its bridges, the market square, the wall with its gates.
- Press R a few times: every seed is a different town.
- Press C for the dungeon: find the key, open the boss room. M shows the map you walked.
